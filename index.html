UCSF Cranial Accelerometry Lab (CAL)

Applications for collection and analysis of headpulse data

Downloads and version info are hosted on this site via the stafne/cal GitHub Releases.

HP Anesthesia

Real-time Headpulse monitoring and analysis for macOS

This app takes live streamed data from HP headsets and graphs a frequency waterfall of the signals. Used primarily for intraoperative monitoring and is a useful app to observe your own headpulse during cognitive activities. Allows annotations as well.

HP Controller

Professional BLE device controller for HP data collection systems

Use the app to program the headset for research recordings, measure bettery level, stream data as a test and perform other utility functions

HP Sleep

Sleep monitoring and analysis application for macOS

This is a comprehensive tool for analysis of sleep data with or without .EDF data imported from EEG based sleep devices.

HP Attention

Attention and cognitive workload monitoring for macOS

HP Merge

Merge and process multiple HP signal files for macOS

This application allows you to merge multiple HP signal files into a single file, with support for metadata integration and comprehensive signal processing.

HP ICU

ICU signal review and analysis for macOS

Process and visualize HP headset accelerometer and related signals for intensive-care monitoring workflows, with HDF5 export and trace-based review aligned with other CAL apps.
